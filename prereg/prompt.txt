Build Chaos Commerce, a parody online store so bad that shoppers wonder how it's still in business, with ridiculous prices, five-star reviews full of fury and two-star reviews full of praise, a one-star button that dodges the cursor, a returns process buried in pointless checks, and any other absurd details you invent. Structure the store so its frontend can be deployed to GitHub Pages and its backend to AWS Lambda, with the Conductor URL read from configuration, and make one command register the workflows, start everything and serve the store at http://localhost:3000 without calling AI APIs at runtime. Nobody can answer questions during this unattended run, so wherever an instruction or skill says to ask, pick a sensible default, write it down in the README along with how to run and deploy the store, and keep going.
